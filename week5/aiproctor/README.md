# Week 5 Capstone: AI Proctor — Code Plagiarism & AI-Submission Detection

## Overview
**AI Proctor** is an intelligent academic integrity system built to detect student plagiarism and unauthorized AI-generated code submissions in programming assessments. It combines algorithmic similarity detection (MOSS / Winnowing), abstract syntax tree (AST) bug signature matching, AI model reference baselines, and an autonomous LLM investigator agent.

## Dual-Stage Architecture (Cost-Optimized)
1. **Tier 1: Free Offline Batch Scan (`main.py`)**:
   - **MOSS Fingerprinting (`moss.py`)**: Tokenizes code into k-grams, computes hashes with winnowing, and calculates Jaccard / token overlap similarity.
   - **Same-Bug AST Matching (`same_bug.py`)**: Detects identical erroneous logic or unusual corner-case bugs shared between classmates.
   - **AI Baseline Proximity (`reference.py`)**: Compares submissions against reference solutions generated by GPT-OSS-120B and Qwen models.
   - **Heuristic Style Scorer (`ai_judge.py`)**: Analyzes code formatting, comment patterns, naming conventions, and docstrings characteristic of LLMs.
2. **Tier 2: Targeted LLM Investigator Agent (`agent.py`)**:
   - Only flagged, high-suspicion submissions are escalated to the reasoning agent.
   - The agent inspects code differentials, syntax patterns, and student explanations to render a final verdict with an evidence audit trail.

## Tech Stack
- **Python AST & Tokenizer**: Syntax tree inspection and language tokenization.
- **Groq API**: High-speed LLM inference for the investigative agent.
- **Evaluation Benchmark**: Test problems (`longest_substring`, `max_subarray`, `two_sum`, `valid_parentheses`) with real classmate submissions and reference outputs.
